# Результаты KBO

## Что делает навык

Получает информацию о матчах KBO на конкретную дату через пакет `kbo-game` и структурирует расписание, счёт и статус матчей.

## Граничное примечание

Этот навык остаётся как `legacy-only`. Замена для российских футбольных сводок уже реализована в `rpl-results`, поэтому `kbo-results` не расширяется за пределы backward compatibility и reference scoreboard flow.

## Когда использовать

- «Покажи результаты матчей KBO сегодня»
- «Покажи счёт матча Ханхва вчера»
- «Структурируй расписание KBO на 2026-04-01»

## Предварительные условия

- Node.js 18+
- `npm install -g kbo-game`

## Входные данные

- Дата: `YYYY-MM-DD`
- Опционально: название конкретной команды

## Рабочий процесс

### 0. Установить пакет глобально при отсутствии

Если под `npm root -g` нет `kbo-game`, не обходить альтернативными реализациями, а сначала попробовать глобальную установку Node-пакета.

```bash
npm install -g kbo-game
```

Не автоматически выбирать другой неофициальный источник таблицы результатов из-за отсутствия пакета.

### 1. Получить данные по дате

```bash
GLOBAL_NPM_ROOT="$(npm root -g)" node --input-type=module - <<'JS'
import path from "node:path";
import { pathToFileURL } from "node:url";

const entry = pathToFileURL(
  path.join(process.env.GLOBAL_NPM_ROOT, "kbo-game", "dist", "index.js"),
).href;
const { getGame } = await import(entry);

const date = "2026-03-25";
const games = await getGame(new Date(`${date}T00:00:00+09:00`));
console.log(JSON.stringify(games, null, 2));
JS
```

Для `kbo-game@0.0.2` фактический export — только `getGame`, и передача строковой даты (`"2026-03-25"`) напрямую не работает. Всегда преобразовывать в объект `Date` перед вызовом. Поскольку по умолчанию используется глобальная установка, во inline-сниппете entry file импортируется напрямую из-под глобального npm root.

### 2. Нормализовать для человека

Не отправлять исходные данные как есть, а структурировать по следующим критериям:

- Хозяева vs Гости
- Статус проведения или завершение матча
- Счёт
- При необходимости фильтровать только конкретную команду

### 3. Держать ответ компактным

Если пользователь хочет таблицу результатов, начинать с однострочного резюме по каждому матчу.

## Критерии завершения

- Есть резюме всех матчей по дате
- При запросе фильтра по команде — остались только матчи этой команды
- Raw JSON доступен по отдельному запросу

## Возможные ошибки

- Изменение сайта KBO может сломать ответы пакета
- Для дат вне сезона может прийти пустой результат

## Примечания

- Этот навык предназначен только для чтения
- Относительные даты вроде «сегодня/вчера» всегда преобразовывать в абсолютные даты перед выполнением
