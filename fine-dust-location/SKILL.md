# Мелкая пыль по местоположению

## Что делает навык

По умолчанию навык обращается к опубликованной совместимой отчётной конечной точке `https://k-skill-proxy.nomadamas.org/v1/fine-dust/report` и возвращает короткую сводку по PM10, PM2.5 и общей категории качества воздуха.

## Граничное примечание

Этот навык остаётся устаревшей/переходной утилитой, а не новым целевым направлением `ru-skill`. Он нужен, чтобы сохранить совместимость с AirKorea + `k-skill-proxy`, а опубликованный адрес прокси и устаревшее именование существуют только как слой совместимости, а не как новый продуктовый путь по умолчанию для русскоязычных сценариев.

## Когда использовать

- "Какая сейчас мелкая пыль в районе Каннама?"
- "Покажи PM2.5 рядом с моей локацией"
- "Насколько сейчас хорошее качество воздуха здесь?"

## Входные данные

- Обычный ввод: название района или подсказка о местоположении
- Для повторного запроса: точное имя станции замера

## Как задавать регион

Лучше всего передавать **корейское административное название, близкое к имени станции измерения**.

- Хорошо: `강남구`, `서울 강남구`, `종로구`, `수원시`
- Неоднозначно: `강남`, `서울 남쪽`, `코엑스 근처`

Если в подсказке несколько лексем, вспомогательный скрипт или прокси обычно берут **самую конкретную часть**. Пример: `서울 강남구` -> `강남구`.

## Путь по умолчанию

Отдельный клиентский слой API не нужен: обычно достаточно прямого запроса HTTP к отчётной конечной точке.

```bash
curl -fsS --get 'https://k-skill-proxy.nomadamas.org/v1/fine-dust/report' \
  --data-urlencode 'regionHint=서울 강남구'
```

Локальный вспомогательный скрипт использует ту же отчётную конечную точку как режим совместимости по умолчанию.

```bash
python3 scripts/fine_dust.py report --region-hint '서울 강남구' --json
```

## Порядок разрешения учётных данных

1. Если значение уже есть в переменной окружения, использовать его как есть.
2. Если агент работает с хранилищем секретов, извлечь значение оттуда и передать в окружение.
3. Если переменные окружения пусты, сначала искать `~/.config/ru-skill/secrets.env`, затем устаревший резерв `~/.config/k-skill/secrets.env`.
4. Если значений нет, запросить у пользователя `AIR_KOREA_OPEN_API_KEY` для прямого резервного доступа или прокси на собственном сервере. `KSKILL_PROXY_BASE_URL` спрашивать только если нужно явное переопределение адреса.

`KSKILL_PROXY_BASE_URL` не считается учётными данными: это только необязательное переопределение адреса. Реальным секретом остаётся `AIR_KOREA_OPEN_API_KEY`, если опубликованный совместимый прокси не используется.

## Неоднозначные локации

Если региональная подсказка не соотносится с одной станцией, прокси вернёт `ambiguous_location` и список кандидатов.

Пример:

```bash
curl -fsS --get 'https://k-skill-proxy.nomadamas.org/v1/fine-dust/report' \
  --data-urlencode 'regionHint=광주 광산구'
```

После этого нужно выбрать одну из `candidate_stations` и повторить запрос уже через `stationName`.

```bash
curl -fsS --get 'https://k-skill-proxy.nomadamas.org/v1/fine-dust/report' \
  --data-urlencode 'stationName=우산동(광주)'
```

## Как отвечать пользователю

Сначала сводите только главное:

- станция измерения
- время запроса
- значение и категория PM10
- значение и категория PM2.5
- итоговая категория качества воздуха
- режим запроса (`прокси` или `запасной вариант`)

## Возможные ошибки

- `regionHint` слишком широкий и не даёт выбрать одну станцию
- прокси недоступен или ключ вышестоящего API отсутствует
- подсказка о местоположении не совпадает с фактическим названием станции, и нужен прямой резервный доступ

## Примечания

- Базовый путь совместимости остаётся отчётная конечная точка на `k-skill-proxy.nomadamas.org`.
- `KSKILL_PROXY_BASE_URL` задаётся только если нужно заменить опубликованный прокси на другой адрес; это не секрет и не обязательная часть стартовой настройки.
- Для поиска по местоположению сначала получайте кандидатов, а затем при необходимости делайте точный запрос по `stationName`.
- Детали сквозного и прямого доступа к AirKorea лучше не повторять в каждом ответе пользователю, если они не нужны для решения задачи.
- Прокси по умолчанию не должен интерпретироваться как сигнал, что мелкая пыль снова стала активным целевым сценарием репозитория.
