# Яндекс.Расписания — yandex-rasp

## Что делает навык

Пакет `yandex-rasp` — это клиент только для чтения для публичного программного интерфейса Яндекс.Расписаний. Покрывает три базовых сценария: поиск станции по названию, расписание для станции и поиск рейсов между двумя точками.

## Предварительные условия

- Бесплатный ключ программного интерфейса Яндекс.Расписаний: https://yandex.ru/dev/rasp/
- Переменная окружения `YANDEX_RASP_API_KEY` или передача ключа через `opts.apiKey`

## Входные данные

| Сценарий | Вход | Пример |
| --- | --- | --- |
| Поиск станции | Подстрока названия | `searchStations("Казанский")` |
| Расписание станции | Код станции + опционально дата, тип, направление | `getStationSchedule("s9600013", { date: "2026-04-10" })` |
| Поиск маршрута | Коды двух станций/городов + опционально дата, тип транспорта | `searchTrips("c146", "c159", { date: "2026-04-10" })` |

## Рабочий процесс

1. Вызвать `searchStations("название")` для поиска нужной станции
2. Взять `yandexCode` из результата
3. Вызвать `getStationSchedule(yandexCode, opts)` для получения расписания или `searchTrips(from, to, opts)` для поиска маршрута

## Как использовать для железнодорожного перенаправления

- Для российского железнодорожного обнаружения достаточно `searchTrips(from, to, opts)` и полей `thread.number`, `carrier`, `departure`, `arrival`, `duration`, `hasTransfers`, `ticketsInfo.places`.
- Если пользователю нужен именно билет, пакет возвращает данные для выбора рейса, но само оформление заказа не автоматизирует: покупку нужно завершать вручную во внешнем пользовательском потоке РЖД или агрегатора.
- Отдельный навык-перенаправление поверх `yandex-rasp` сейчас не заводится: в репозитории это зафиксировано как документная граница замены для устаревших навыков `srt-booking` и `ktx-booking`.

      "from": { "code": "s9600013", "title": "Москва, Казанский вокзал" },

## Что важно проверять в ответе

- `thread.transportType` — тип транспорта: `suburban`, `train`, `bus`, `plane`
- `departure` / `arrival` — ISO 8601 с часовым поясом
- `days` — регулярность рейса
- `ticketsInfo.places` — доступные классы и цены
- `hasTransfers` — наличие пересадок
- `pagination.total` — сколько всего результатов доступно

## Ограничения

- Требуется ключ программного интерфейса (бесплатный, но регистрация обязательна)
- Справочник станций (~40 МБ) лучше буферизовать на клиенте
- Только для чтения, без покупки билетов
- Не создаёт и не поддерживает отдельные прямые ссылки или интеграции оформления заказа поверх РЖД, `tutu.ru` или Яндекс Путешествий
- Не покрывает полный охват всех типов транспорта, если они не указаны в документации программного интерфейса
