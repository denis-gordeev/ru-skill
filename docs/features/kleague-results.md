# Руководство по результатам K League

## Граничное примечание

Этот сценарий остаётся `устаревший без развития`: для российских футбольных сводок его замена уже реализована как `rpl-results`. `kleague-results` сохраняется ради обратной совместимости и как эталонный сценарий для официальных расписаний и таблиц, но не должен подаваться как незавершённый перечень задач целевой линейки.

## Что делает навык

- Показывать расписание и результаты матчей K League 1 и K League 2 по дате.
- Фильтровать матчи по конкретной команде (`FC서울`, `서울 이랜드`, код команды и т.п.).
- Возвращать текущую турнирную таблицу.

## Предварительные условия

- Node.js 18+
- `npm install -g kleague-results`

## Входные данные

- Дата: `YYYY-MM-DD`
- Лига: `K리그1` или `K리그2`
- Необязательно: имя команды, полное название или код

## Официальные интерфейсы

Здесь используется не HTML-разбор, а официальный JSON и официальные интерфейсы API.

- Расписание и результаты: `https://www.kleague.com/getScheduleList.do`
- Таблица команд: `https://www.kleague.com/record/teamRank.do`

## Рабочий процесс

1. Если пакет не установлен, сначала поставить `kleague-results`, а не искать обходы.
2. Через `getScheduleList.do` получить данные за нужный месяц и затем отфильтровать ровно нужную дату.
3. Если указана команда, считать эквивалентными псевдонимы вроде `서울`, `FC서울`, `K09`.
4. Через `teamRank.do` подтянуть текущую турнирную таблицу и показать её вместе с результатами матчей.

## Пример

```bash
GLOBAL_NPM_ROOT="$(npm root -g)" node --input-type=module - <<'JS'
import path from "node:path";
import { pathToFileURL } from "node:url";

const entry = pathToFileURL(
  path.join(process.env.GLOBAL_NPM_ROOT, "kleague-results", "src", "index.js"),
).href;
const { getKLeagueSummary } = await import(entry);

const summary = await getKLeagueSummary("2026-03-22", {
  leagueId: "K리그1",
  team: "FC서울",
  includeStandings: true,
});

console.log(JSON.stringify(summary, null, 2));
JS
```

## Ограничения

- `getScheduleList.do` возвращает месяц целиком, поэтому фильтрация по точной дате обязательна.
- Таблица сейчас берётся в режиме `stadium=all`; при необходимости можно позже расширить до дома/на выезде.
- Короткие названия вроде `서울` могут обозначать разные клубы в разных лигах, поэтому в K League 2 нужно отдельно проверять `서울 이랜드`.
- До завершения матча статус может быть `Запланирован` или `В процессе`.
- Пока пакет новый, до релиза его стоит проверять через локальное рабочее пространство или архивный артефакт, а публикацию делать уже после слияния.

Историческое описание для документных регрессий: `Результаты K League`.
