# Руководство по CLI для KakaoTalk на macOS

## Граничное примечание

Этот сценарий остаётся `устаревший без развития`: он нужен для обратной совместимости и как эталонный сценарий локальной macOS-автоматизации, но не считается новым российским направлением целевой линейки репозитория. Пока нет подтверждённой русскоязычной замены на базе публичного источника с сопоставимой ценностью и безопасностью, `kakaotalk-mac` не должен выглядеть как скрытый перечень задач на новую интеграцию мессенджера.

## Что делает навык

- Читать список недавних чатов в KakaoTalk на macOS.
- Показывать последние сообщения из конкретной комнаты.
- Искать по всем чатам по ключевому слову.
- Безопасно отправлять тестовые сообщения в чат с собой.
- После подтверждения пользователя отправлять сообщение в выбранный чат.

## Предварительные условия

- macOS
- Установленный KakaoTalk для Mac
- Homebrew
- `brew install silver-flight-group/tap/kakaocli`
- Для терминала выданы права **Полный доступ к диску (Full Disk Access)** и **Универсальный доступ (Accessibility)**

Если приложение KakaoTalk ещё не установлено, его можно поставить через `mas`.

```bash
brew install mas
mas account
mas install 869223134
```

## Входные данные

- Название чата
- Ключевое слово для поиска
- Период (`--since 1h`, `--since 7d` и т.п.)
- Текст сообщения
- Режим теста (`--me`, `--dry-run`)

## Рабочий процесс

1. Проверить, что установлен KakaoTalk для Mac и `kakaocli`.
2. Сначала убедиться через `kakaocli status` и `kakaocli auth`, что права и доступ к БД работают.
3. Для чтения и поиска запускать команды в JSON-режиме, затем уже сводить ответ в человекочитаемый вид.
4. Перед реальной отправкой сначала тестировать через `--me` или `--dry-run`.
5. В чужие чаты отправлять сообщения только после явного подтверждения пользователя.

## Примеры

```bash
kakaocli status
kakaocli auth
kakaocli chats --limit 10 --json
kakaocli messages --chat "Jisoo" --since 1d --json
kakaocli search "встреча" --json
kakaocli send --me _ "тестовое сообщение"
kakaocli send --dry-run "рабочий чат" "встречаемся сегодня в 15:00"
```

## Ограничения

- Без **Полный доступ к диску (Full Disk Access)** могут падать даже команды только для чтения.
- Без **Универсальный доступ (Accessibility)** ломается отправка и автоматизация подобных harvest действий по сбору данных.
- Это сценарий только для macOS; не нужно молча переключаться на Windows/Linux-обходы.
- Сообщения другим людям нельзя отправлять без отдельного подтверждения.
