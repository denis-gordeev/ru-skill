# Поиск поблизости Zoon.ru

Поиск ближайших заведений и организаций через публичные страницы Zoon.ru.

## Что делает навык

`zoon-nearby` — это дополнительный источник только для чтения для поиска ближайших в российских городах через страницы с серверной отрисовкой Zoon.ru. Навык дополняет `osm-nearby`: к координатам и базовым данным он добавляет рейтинги, телефоны, режим работы, описания и детальные карточки организаций.

## Когда использовать

- Используй `osm-nearby`, когда нужны только координаты и базовые данные заведений (`бесплатный`, `без API-ключа`, самый быстрый путь)
- Используй `zoon-nearby`, когда нужны рейтинги, отзывы, телефоны, режим работы и другие детали организаций
- Используй `zoon-nearby`, когда запрос задан через город и категорию, а не через точные координаты
- Используй `getBusinessDetails`, когда пользователь уже прислал URL карточки Zoon.ru и просит разобрать конкретное заведение

## Предварительные условия

- Секреты и API-ключи не нужны
- Нужен сетевой доступ к публичным страницам с серверной отрисовкой (SSR) `zoon.ru`
- Для поиска нужен как минимум город и тип заведения либо текстовый запрос
- Для детальной карточки нужен полный URL страницы организации на Zoon.ru

## Входные данные

- Название города на русском (`Москва`, `Санкт-Петербург`, `Казань`)
- Категория или тип заведения (`restaurants`, `cafes`, `bars`, `hotels`, `pharmacies`)
- Текстовый поисковый запрос для общего поиска
- Номер страницы при постраничной навигации
- Полный URL карточки заведения для `getBusinessDetails`

## Рабочий процесс

```bash
npm install zoon-nearby
```

1. Выбери `osm-nearby` как основной источник, если пользователь просит просто результаты поиска ближайших без расширенных метаданных.
2. Переключись на `zoon-nearby`, если нужны рейтинги, телефоны, описания или городо-ориентированный поиск по категориям.
3. Для категорий используй `searchRestaurants`, `searchCafes`, `searchBars` или `searchByCategory`.
4. Для свободного поиска по тексту используй `search(query, city?, opts?)`.
5. Если пользователь дал ссылку на карточку организации, вызови `getBusinessDetails(businessUrl, opts?)`.
6. Верни краткую сводку по найденным организациям и явно отмечай, если телефон, рейтинг или режим работы отсутствуют на странице.

Основные функции:

- `searchRestaurants(city, opts?)`
- `searchCafes(city, opts?)`
- `searchBars(city, opts?)`
- `searchByCategory(city, category, opts?)`
- `search(query, city?, opts?)`
- `getBusinessDetails(businessUrl, opts?)`

## Критерии завершения

- Пользователь получил список организаций или детальную карточку конкретного заведения
- В ответе есть минимум название, адрес и ссылка; рейтинг, телефон и режим работы добавлены, если доступны
- Для поиска по городу и категории понятно, какую категорию и страницу ты использовал
- Для URL-карточки явно указано, что данные взяты с публичной страницы Zoon.ru

## Возможные ошибки

- Название города неоднозначно или не совпадает с идентификатором категории/структурой Zoon.ru
- На странице нет телефона, часов работы или рейтинга, хотя пользователь их ожидал
- Вёрстка с серверной отрисовкой (SSR) Zoon.ru изменилась и часть полей перестала стабильно извлекаться
- Пользователь просит поиск ближайших по координатам, где `osm-nearby` подходит лучше, чем поиск по городу/категории через Zoon

## Примечания

- Источник: публичные страницы с серверной отрисовкой (SSR) Zoon.ru
- Защита от ботов в текущем сценарии не требуется
- Навык остаётся дополнительным источником рядом с `osm-nearby`, а не заменой координатного поиска ближайших
- Примеры типовых запросов:

```text
Найди рестораны в Москве
Покажи кафе в Санкт-Петербурге
Какие бары есть в Казани?
Дай подробную информацию о ресторане по ссылке https://zoon.ru/msk/restaurants/pushkin
```
