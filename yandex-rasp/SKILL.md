# Расписания Яндекс

## Что делает навык

Ищет станции, получает расписание рейсов для конкретной станции и ищет маршруты между двумя городами или станциями через программный интерфейс Яндекс.Расписаний. Охватывает электрички, поезда дальнего следования, автобусы и авиарейсы по России.

## Когда использовать

- Когда нужно узнать расписание электричек, поездов или автобусов для российской станции
- Когда нужно найти маршрут между двумя городами с пересадками
- Когда нужен поиск станции по названию

## Предварительные условия

- Ключ программного интерфейса Яндекс.Расписаний (бесплатный, без регистрации на сайте)
- `npm install yandex-rasp`
- Переменная окружения `YANDEX_RASP_API_KEY` или передача ключа через `opts.apiKey`

## Входные данные

- Поисковый запрос станции (название, например «Казанский вокзал»)
- Код станции Яндекс (например `s9600013`) для расписания
- Коды двух станций/городов для поиска маршрута
- Необязательные фильтры: дата, тип транспорта, направление

## Рабочий процесс

1. Найти станции по названию через `searchStations`
2. Получить расписание для нужной станции через `getStationSchedule` или найти маршрут через `searchTrips`
3. Вернуть нормализованные результаты: время отправления/прибытия, номер рейса, перевозчик, платформа
4. Если пользователь хочет купить билет на поезд, использовать результат как основу обнаружения/перенаправления и отправлять в официальное внешнее оформление заказа вручную, без попытки автоматизировать оплату

## Критерии завершения

- Найдены станции по названию с кодами Яндекс и ЕССР
- Возвращено расписание с временем отправления/прибытия, номером рейса и перевозчиком
- Возвращены маршруты между станциями с длительностью, ценой и наличием пересадок
- Ошибки программного интерфейса проброшены с понятным сообщением

## Возможные ошибки

- Нет ключа программного интерфейса — выбрасывается ошибка с инструкцией получить ключ
- Станция не найдена — пустой массив результатов
- Программный интерфейс вернул ошибку — пробрасывается с кодом статуса и телом ответа

## Примечания

- Конечная точка `stations_list` возвращает полный справочник всех станций (~40 МБ), имеет смысл сохранять в буфер
- Клиент использует актуальный узел `api.rasp.yandex-net.ru`, а не устаревший `api.rasp.yandex.net`
- Только для чтения, без покупки билетов и операций записи
- Отдельный железнодорожный навык перенаправления поверх `yandex-rasp` не нужен, пока нет подтверждённого публичного программного интерфейса бронирования: для замены устаревших навыков здесь зафиксирована граница `обнаружение + ручное внешнее перенаправление`
