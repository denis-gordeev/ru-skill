# Поиск на Яндекс Маркете

## Что делает навык

Ищет товары на Яндекс Маркете по запросу и открывает карточку конкретного товара по адресу из результатов поиска. Нормализует цену, рейтинг, число оценок и базовые характеристики без ключа API и без автоматизации через обозреватель.

## Когда использовать

- Когда нужно быстро найти товар на российской торговой площадке по названию
- Когда нужен обзор карточки товара только для чтения с ценой и характеристиками
- Когда нужно заменить устаревший сценарий `daiso-product-search` на российский источник

## Предварительные условия

- Публичный доступ к `market.yandex.ru`
- `npm install yandex-market-search`
- Никакие секреты, ключи API и посредники не нужны

## Входные данные

- Поисковый запрос товара, например `iphone 16`, `пылесос xiaomi`, `кофемашина delonghi`
- Необязательная страница результатов `page`
- Адрес карточки товара из `searchProducts(...)`

## Рабочий процесс

1. Вызвать `searchProducts("название товара")`
2. Выбрать релевантный результат по `title`, `price`, `rating` и встроенным характеристикам
3. Передать `url` из результата в `getProduct(url)` для чтения полной карточки
4. Вернуть нормализованные поля: цена, рейтинг, число оценок, описание и характеристики

## Критерии завершения

- В поиске есть нормализованный список карточек с каноническим адресом без отслеживающих параметров запроса
- Карточка товара возвращает `title`, `brand`, `price`, `rating`, `reviewCount` и `specs`
- Источник явно помечен как `market.yandex.ru`

## Возможные ошибки

- Яндекс Маркет вернул код ответа, отличный от 200 — пробрасывается ошибка с кодом ответа
- Вёрстка изменилась и ключевые поля не распознаны — частичные поля остаются `null`, но канонический адрес и доступные характеристики возвращаются
- Пустая выдача по запросу — возвращается пустой `results`

## Примечания

- Текущий минимальный рабочий вариант опирается на HTML с серверной отрисовкой поисковой выдачи и страницы карточки товара
- Операции записи не поддерживаются: корзина, покупка, избранное и отзывы вне области действия
- Если Яндекс Маркет переведёт выдачу в чистую клиентскую отрисовку или режим защиты от роботов, источник нужно будет переоценить в `docs/sources.md`
