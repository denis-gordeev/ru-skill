# Бронирование KTX

## Граничное примечание

Этот навык сохраняется как `устаревший без развития` корейский железнодорожный сценарий. Он нужен ради обратной совместимости и не должен использоваться как шаблон для новых российских интеграций на запись: для российских поездов базовым источником только для чтения остаётся `yandex-rasp`, а граница замен закреплена в `docs/booking-replacements.md`.

## Что делает навык

Обрабатывает поиск, бронирование, проверку и отмену билетов KTX/Korail через вспомогательный скрипт `scripts/ktx_booking.py` поверх `korail2`.

Из-за проверки защиты от ботов Dynapath в приложении Korail стандартные примеры `korail2` 0.4.0 могут вызывать `MACRO ERROR`. Этот навык предполагает, что вспомогательный скрипт восстанавливает рабочий процесс бронирования, добавляя `x-dynapath-m-token`, `Sid` и актуальную версию приложения (`250601002`).

## Когда использовать

- "Найди места KTX из Сеула в Пусан"
- "Проверь бронирования Korail"
- "Отмени KTX"
- "Выбери самый быстрый поезд после 9 утра"

## Когда не использовать

- Для бронирования SRT
- Для автоматизации до подтверждения оплаты
- Для хранения учётных данных в открытом виде
- Если нужен новый российский железнодорожный сценарий: в целевой линейке для этого базовым путём считается `yandex-rasp`, а не расширение устаревших навыков бронирования.

## Предварительные условия

- Python 3.10+
- `python3 -m pip install korail2 pycryptodome`

## Необходимые переменные окружения

- `KSKILL_KTX_ID`
- `KSKILL_KTX_PASSWORD`

### Порядок разрешения учётных данных

1. **Если переменная окружения уже установлена**, использовать её напрямую.
2. **Если агент использует собственное хранилище секретов** (1Password CLI, Bitwarden CLI, Связка ключей macOS и т.д.), извлечь оттуда и внедрить как переменную окружения.
3. **Если переменных окружения нет**, сначала искать значения в `~/.config/ru-skill/secrets.env`, затем в унаследованный запасной вариант `~/.config/k-skill/secrets.env`.
4. **Если ничего нет**, запросить у пользователя и сохранить в хранилище секретов или `secrets.env`.

Сохранение в путь по умолчанию — это запасной вариант, а не требование.

## Входные данные

- Станция отправления
- Станция назначения
- Дата: `YYYYMMDD`
- Желаемое время отправления: `HHMMSS`
- Количество пассажиров и тип пассажира
- Предпочтение по месту
- `train_id` из результатов поиска

## Рабочий процесс

### 0. Установка пакета при отсутствии

Если `python3 -c 'import korail2, Crypto'` завершается ошибкой, сначала попробуйте глобальную установку пакетов Python вместо поиска альтернатив.

```bash
python3 -m pip install korail2 pycryptodome
```

### 1. Обеспечение доступа к учётным данным

Проверьте наличие переменных окружения `KSKILL_KTX_ID` и `KSKILL_KTX_PASSWORD`. При отсутствии получите их согласно порядку разрешения учётных данных выше.

Не пытайтесь напрямую разбирать сайты или использовать другие неофициальные пути из-за отсутствия секретов.

### 2. Первоначальный поиск через вспомогательный скрипт

Всегда выполняйте поиск через вспомогательный скрипт.

```bash
python3 scripts/ktx_booking.py search 서울 부산 20260328 090000 --limit 5
```

Для включения поездов без мест добавьте `--include-no-seats`, для совместного отображения поездов с ожиданием бронирования добавьте `--include-waiting-list`.

### 3. Представление короткого списка

Перед бронированием всегда подтверждайте:

- `index`
- `train_id`
- Время отправления/назначения
- Статус KTX
- Доступность обычного/первоклассного места
- Возможность ожидания бронирования

### 4. Бронирование только после однозначного выбора поезда

Бронируйте только после выбора `train_id` из результатов поиска. Это значение — стабильный идентификатор выбора, который вспомогательный скрипт создаёт из номера поезда/даты эксплуатации/времени/кода станции, поэтому при повторном поиске тот же поезд будет выбран, а при отсутствии — завершится ошибкой.

```bash
python3 scripts/ktx_booking.py reserve 서울 부산 20260328 090000 --train-id <train_id> --seat-option general-first
```

Ответ включает номер бронирования, тариф и срок оплаты. **Оплата не автоматизируется.**
При отсутствии мест на этапе поиска включите `--include-waiting-list`, а на этапе бронирования добавьте `--try-waiting` для попытки ожидания бронирования.

### 5. Проверка или отмена

Отмену выполняйте только после идентификации целевого бронирования через повторный поиск.

```bash
python3 scripts/ktx_booking.py reservations
```

```bash
python3 scripts/ktx_booking.py cancel <reservation_id>
```

## Критерии завершения

- Для поиска: кандидаты поездов отобраны
- Для бронирования: результат бронирования и срок оплаты подтверждены
- Для отмены: понятно, какое бронирование отменено

## Возможные ошибки

- Ошибка входа
- Полная распродажа мест
- Изменение правил защиты от ботов Korail

## Примечания

- `scripts/ktx_booking.py` — вспомогательный скрипт, компенсирующий регрессию защиты от ботов в исходном пакете `korail2`
- `korail2` — специальный интерфейс для KTX/Korail, поэтому тип поезда и модель пассажира очевидны
- Этот навык относится к устаревшему коридору репозитория и не должен расширяться в сторону новых российских потоков оформления заказа/записи.
- Оплата до завершения не автоматизируется
- Избегайте агрессивного опроса
