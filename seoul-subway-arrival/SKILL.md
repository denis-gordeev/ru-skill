# Прибытие поездов метро Сеула

## Что делает навык

Сводит информацию о прибывающих поездах по станциям через открытый API реального времени метрополитена Сеульского открытого портала данных.

## Когда использовать

- "Через сколько минут прибудет поезд на Каннам?"
- "Покажи информацию о прибытии на 1-й линии станции Сеул"
- "Сведи поезда, которые скоро прибудут на станцию Чамсиль"

## Предварительные условия

- Ключ API Сеульского открытого портала данных
- опционально: `jq`

## Граничное примечание

Этот навык сохраняется как `устаревший без развития`. Он полезен для обратной совместимости со старым корейским набором сценариев, но не считается активным целевым направлением `ru-skill`, потому что сопоставимый российский навык метро реального времени через публичные бесплатные API пока не подтверждён.

## Требуемые переменные окружения

- `SEOUL_OPEN_API_KEY`

### Порядок разрешения учётных данных

1. **Если уже есть в переменных окружения** — использовать как есть.
2. **Если агент использует собственное хранилище секретов (1Password CLI, Bitwarden CLI, Связка ключей macOS и т.д.)** — извлечь оттуда и внедрить в переменную окружения.
3. **`~/.config/ru-skill/secrets.env`** — основной простой файл окружения (dotenv) — запасной вариант, права `0600`.
4. **`~/.config/k-skill/secrets.env`** — обратно совместимый запасной вариант, если новый путь ещё не заведён.
5. **Если ничего нет** — спросить у пользователя и сохранить в 2, 3 или 4.

Сохранение в путь по умолчанию — лишь запасной вариант, не обязательное требование.

## Входные данные

- Название станции
- Опционально: количество записей для получения

## Рабочий процесс

### 1. Убедиться в наличии учётных данных

Проверить, установлена ли переменная окружения `SEOUL_OPEN_API_KEY`. Если нет — получить её согласно порядку разрешения учётных данных выше.

Не переключаться автоматически на неофициальные зеркальные API или другие источники из-за отсутствия секретов.

### 2. Запросить официальную конечную точку прибытия на станцию

Сеульский API метро реального времени предоставляет информацию о прибытии в реальном времени по станциям в формате JSON/XML. Базовый пример запроса использует следующий шаблон.

```bash
curl -s "http://swopenAPI.seoul.go.kr/api/subway/${SEOUL_OPEN_API_KEY}/json/realtimeStationArrival/0/8/강남"
```

### 3. Свести ответ

По возможности свести только следующие поля.

- Линия
- Направление (вверх/вниз или внешняя/внутренняя)
- Первое сообщение о прибытии
- Второе сообщение о прибытии
- Время до прибытия (если есть, в секундах)

### 4. Консервативно относиться к данным реального времени

Данные реального времени могут меняться каждые несколько секунд, поэтому в ответе всегда указывать время запроса.

## Критерии завершения

- Сведены поезда, ожидающие прибытия на запрошенную станцию
- Указано время запроса данных реального времени
- Ключ не раскрыт

## Возможные ошибки

- Ключ API не установлен
- Превышение квоты
- Несоответствие названия станции

## Примечания

- Руководство Сеульского открытого портала данных указывает, что на открытый API метро реального времени могут быть суточные лимиты вызовов
- Пути конечных точек могут изменяться с версией API, поэтому при сбое перепроверять актуальные примеры адресов в консоли наборов данных
