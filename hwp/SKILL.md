# HWP

## Граничное примечание

Этот навык классифицируется как `целевой-вспомогательный`: он обрабатывает корейский формат документов HWP (Хангул), для которого нет прямого российского аналога, но он полезен как самостоятельная утилита для конвертации документов. Навык не входит в целевую линейку российских сценариев, но сохраняется и поддерживается как полезный инструмент для работы с документами HWP.

## Что делает навык

Читает `.hwp`-документы и конвертирует их в JSON / Markdown / HTML, извлекает изображения и выполняет пакетную обработку.
Если среда — **Windows + установлена программа Хангул (HWP) + требуется прямое управление программой**, выбирается `hwp-mcp`; во всех остальных случаях по умолчанию используется `@ohah/hwpjs`.

## Когда использовать

- «Переведи этот файл HWP в Markdown»
- «Извлеки только изображения из документа Хангул»
- «Конвертируй все файлы HWP в папке в JSON»
- «На Windows через программу Хангул заполни таблицу»

## Когда не использовать

- Исходный файл в формате `.hwpx`, `.docx`, `.pdf`
- Среда не Windows или программа Хангул не установлена, но требуется автоматизация редактирования
- Нужен OCR или восстановление сканированного PDF

## Предварительные условия

- Общий путь конвертации: Node.js 18+
- Путь прямого управления: Windows + установлена программа Хангул (HWP) + Python 3.7+
- Права записи в выходной каталог

## Входные данные

- Путь к исходному `.hwp`-файлу или папке
- Желаемый формат вывода: `json`, `markdown`, `html`
- Путь к выходному файлу/каталогу
- Включать/извлекать ли изображения
- Выполнять ли пакетную обработку
- Требуется ли прямое управление программой

## Политика маршрутизации

### По умолчанию: `@ohah/hwpjs`

Используется `@ohah/hwpjs` по умолчанию, если выполняется хотя бы одно из условий:

- macOS / Linux / среда непрерывной интеграции (CI)
- Windows, но нет уверенности в наличии программы Хангул
- Задача ориентирована на чтение / конвертацию / извлечение изображений / пакетную обработку

### Путь прямого управления на Windows: `hwp-mcp`

`hwp-mcp` выбирается только при одновременном выполнении всех условий:

- Операционная система — Windows
- Программа Хангул (HWP) реально установлена
- Требуется **прямое управление запущенной программой Хангул**: создание документа, вставка текста, заполнение таблицы, сохранение

Если условия прямого управления не ясны, не угадывать, а начать с диапазона, который покрывается `@ohah/hwpjs`.

## Рабочий процесс

### 0. Сначала определить среду

```bash
node -p "process.platform"
```

- Если результат не `win32` — `@ohah/hwpjs`
- Если `win32`, но прямое управление программой Хангул не подтверждено — `@ohah/hwpjs`
- Если `win32`, программа Хангул установлена и нужно прямое управление — `hwp-mcp`

### 1. Установить выбранную серверную часть при отсутствии

#### `@ohah/hwpjs`

```bash
npm install -g @ohah/hwpjs
export NODE_PATH="$(npm root -g)"
```

#### `hwp-mcp`

```bash
git clone https://github.com/jkf87/hwp-mcp.git
cd hwp-mcp
pip install -r requirements.txt
```

`hwp-mcp` предполагает Windows и установленную программу Хангул. Если это не так, не продолжать принудительно, а вернуться к `@ohah/hwpjs`.

### 2. Предпочитать `@ohah/hwpjs` для конвертации и извлечения

#### Конвертация в JSON

```bash
hwpjs to-json document.hwp -o output.json --pretty
```

#### Конвертация в Markdown

```bash
hwpjs to-markdown document.hwp -o output.md --include-images
```

`--include-images` встраивает изображения в Markdown как base64 `data:` URI, а не сохраняет их отдельными файлами.
Если нужно сохранить изображения как отдельные файлы, используйте `--images-dir`:

```bash
hwpjs to-markdown document.hwp -o output.md --images-dir ./images
```

#### Конвертация в HTML

```bash
hwpjs to-html document.hwp -o output.html
```

#### Извлечение изображений

```bash
hwpjs extract-images document.hwp -o ./images
```

#### Пакетная обработка

```bash
hwpjs batch ./documents -o ./output --format json --recursive
```

Формат пакетного вывода уточняйте через `hwpjs batch --help` в локальной установленной версии.

### 3. Использовать `hwp-mcp` только для прямого управления HWP на Windows

Зарегистрировать `hwp_mcp_stdio_server.py` в настройках Claude/Codex MCP и использовать для следующих видов задач:

- Создание нового документа
- Вставка текста
- Создание / заполнение таблицы
- Сохранение
- Пакетные задачи из нескольких команд редактирования

Примеры прямого управления ограничены следующими категориями:

- Заполнение шаблона отчёта
- Ввод данных в таблицу
- Создание документа по установленной форме

### 4. Проверять вывод после каждого запуска

- JSON: проверить наличие файла и структуру верхнего уровня
- Markdown: проверить наличие основного текста и встроенных `data:` URI / base64 изображений (при использовании `--include-images`)
- Markdown: если цель — отдельные файлы изображений, проверить, что файлы реально созданы в каталоге `--images-dir`
- HTML: проверить, что файл создан и отображается в браузере
- Извлечение изображений: проверить, что файлы реально созданы в выходном каталоге
- Пакетная обработка: проверить, что количество входных и выходных файлов примерно совпадает

## Критерии завершения

- Результат в запрошенном формате создан
- Если запрашивались изображения — подтверждено наличие извлечённых файлов или встроенных `data:` URI в Markdown
- Для пакетной обработки — зафиксированы диапазон обработки и количество ошибок
- Для задач прямого управления на Windows — зафиксировано, какие операции были выполнены

## Возможные ошибки

- Повреждённый `.hwp`-файл
- Глобальный `hwpjs` не установлен
- Среда не Windows, поэтому `hwp-mcp` недоступен
- Программа Хангул не установлена или не удалось подключиться к автоматизации
- Недостаточно прав на запись в выходной каталог

## Примечания

- Выбор по умолчанию — всегда `@ohah/hwpjs`.
- `hwp-mcp` используется только для прямого управления в среде Windows + установленная программа Хангул.
- Если прямое управление не удалось, но достаточно чтения/конвертации, свернуть до пути `@ohah/hwpjs` и завершить задачу.
